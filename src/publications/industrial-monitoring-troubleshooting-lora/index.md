Peer-reviewed conference publication describing the design and implementation of a real-time industrial monitoring and troubleshooting system using wireless sensor networks based on LoRa communication technology.

The work investigated wireless sensor motes for collecting operational information from industrial machinery and transmitting measurement data to a monitoring interface for diagnostics, troubleshooting, and preventative maintenance.

The publication documents the research associated with the Industrial Internet of Things Monitoring System project developed at Miami University.
